# Releases

IsaxRoles is compatible with desktop releases of Among Us. This includes Steam, Epic Games and itch.io. We do not support cracked versions of Among Us.

|                                       Among Us Version                                        | IsaxRoles Version |                                        Links                                        |
|:---------------------------------------------------------------------------------------------:|:-----------------:|:-----------------------------------------------------------------------------------:|
|                                           `v19.0.0`                                           |   `v2026.10.29`   | [Download](https://github.com/Isax820/IsaxRoles/releases/tag/v2026.10.29) |

| [Reactor](https://github.com/NuclearPowered/Reactor/actions) | `v2.5.1-ci.417` or later |
